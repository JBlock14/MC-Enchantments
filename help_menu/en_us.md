## Help Center

</div>

This platform gathers all the **enchantments** from the game **MINECRAFT** in one place.  
The information is presented in a clear and straightforward way:

- **Enchantment name:** Official identification.
- **Basic description:** Main effect within the game.
- **Item compatibility:** Tools, weapons, or armor pieces that can receive it.

The goal is to provide a simple and accessible reference, with fast navigation and optimized design, like a mini wiki for players who seek simplicity.

---

### Search Bar

Type part of an enchantment's name to find it instantly. Uppercase letters and accents don't matter.

It is not its only utility: the bar also includes shortcuts, commands, and tags that improve exploration of the website.

#### Keyboard shortcuts:

On computers, or any device with a keyboard, you can use these shortcuts outside of text fields:

- **T:** Selects the search bar.
- **/:** Selects the bar and starts typing a command.
- **Esc:** Clears the search and leaves the bar.
- **Arrow keys:** Move you around the bar, the filter and language menus, and the items of each enchantment.

#### Commands:

Commands are used to view additional information or have more control. They start with **/** and are written in lowercase.

**Help and Support**

**`/help`**: Opens this menu, where you will find complete information about the website: utilities, purpose, syntax, and more.

**Appearance and Customization**

**`/theme default`**: Switches to the classic look: simple, comfortable, and lightweight, with basic animations and effects.

**`/theme modern`**: Switches to a modern look with glass effects, blur, and detailed animations. It may reduce performance on low-end devices.

Your appearance choice is saved for your next visit.

#### Tags:

Tags, or search filters, are used to find the enchantments of a specific tool, weapon, or armor piece.  
Unlike group filters, they filter by individual items.  
You can activate several at once: the enchantments that work for any of them will be shown.

It works like this: open the tag with **":"** (colon), type the name of the item (you can usually see it by hovering the mouse over its icon, or by tapping it on touch screens), and close it with another **":"**.  
Write it without extra spaces. Uppercase letters and accents don't matter.

|       TAG       |       FUNCTION        |
| :-------------: | :-------------------: |
|    `:sword:`    |    Filter by sword    |
|     `:axe:`     |     Filter by axe     |
|   `:pickaxe:`   |   Filter by pickaxe   |
|   `:shovel:`    |   Filter by shovel    |
|     `:hoe:`     |     Filter by hoe     |
| `:fishing rod:` | Filter by fishing rod |
|    `:mace:`     |    Filter by mace     |
|   `:trident:`   |   Filter by trident   |
|    `:spear:`    |    Filter by spear    |
|     `:bow:`     |     Filter by bow     |
|  `:crossbow:`   |  Filter by crossbow   |
|   `:helmet:`    |   Filter by helmet    |
| `:chestplate:`  | Filter by chestplate  |
|  `:leggings:`   |  Filter by leggings   |
|    `:boots:`    |    Filter by boots    |

### Filter Button

Organizes the list by a group of items. When pressed, it displays a menu with these options:

- **Armor:** Shows the possible enchantments for armor pieces.
- **Weapons:** Shows the possible enchantments for weapons.
- **Ranged:** Shows the possible enchantments for ranged weapons: bow, crossbow, trident, and spear.
- **Tools:** Shows the possible enchantments for tools.

Active filters, just like tags, appear as bubbles below the bar: press them to remove them.

---

### Language Button

Changes the language of the website. It is detected automatically from your browser, your choice is remembered, and you can search for your language by typing in the dropdown.

This option is still in _BETA_: you may still see translation errors, and the number of languages is very limited.

We try to keep the translation as faithful to the game as possible.
