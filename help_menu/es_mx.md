# **MC Enchantments**
</span>

## Soporte de ayuda
</div>

Esta plataforma junta todos los **encantamientos** del juego **MINECRAFT** en un solo lugar.  
La info se muestra de manera clara y directa:

- **Nombre del encantamiento:** Nombre oficial.  
- **Descripción básica:** Qué hace dentro del juego.  
- **Compatibilidad de objetos:** Herramientas, armas o piezas de armadura que lo pueden tener.  

La idea es dar una referencia sencilla y accesible, con navegación rápida y diseño bien optimizado, funcionando como una mini Wiki-Web para los jugadores que buscan practicidad.

---

### Barra de búsqueda
Puedes usar la barra integrada para moverte más a gusto y encontrar el encantamiento que quieras sin tanto rollo.

En computadoras, o cualquier aparato con teclado, puedes seleccionar la barra rápido presionando la tecla **TAB** una vez, si no está ya seleccionada.

Y no es la única función, también trae atajos y comandos que hacen más chida la exploración.

#### Comandos:
Los comandos de interacción se usan seguido para ver info extra o tener más control. Siempre se escriben en minúsculas.

**`/help`**: Abre este menú donde encontraras toda la info de la página: utilidades, propósito, sintaxis y más.

#### Tags:
Las tags, o filtros de búsqueda, sirven para buscar encantamientos de una herramienta, arma o pieza de armadura específica y limitar la lista a opciones concretas.  
Funcionan como filtros, pero en vez de agrupar, se enfocan en objetos específicos.  
Puedes activar varias al mismo tiempo.

La función es simple: abres la tag con **":"** (dos puntos), escribes el nombre del objeto que quieras filtrar (lo puedes ver pasando el mouse sobre el ícono o tocándolo en pantallas táctiles), y cierras otra vez con **:**.  
Evita meter espacios de más.

### Botón de filtros
El filtrado sirve para organizar la lista con un grupo de objetos.  
Al activarlo se abre un menú con estas opciones:

- **Filtro por armadura:** Muestra todos los encantamientos para piezas de armadura.  
- **Filtro por armas:** Muestra todos los encantamientos para armas.  
- **Filtro por a distancia:** Muestra todos los encantamientos para armas de rango.  
- **Filtro por herramientas:** Muestra todos los encantamientos para herramientas.
